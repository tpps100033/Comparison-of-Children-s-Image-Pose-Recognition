# Data and model licensing boundary

No dataset images, annotations, generated crops, prediction files, or pretrained weights are distributed in this repository. Retrieve assets from their owners, check current terms, and cite them.

| Component | Source | Included here? |
|---|---|---|
| COCO 2017 validation images/keypoint annotations | [COCO](https://cocodataset.org/#keypoints-2017) | No |
| COCO-UniHuman v2 apparent-age/keypoint annotations | [COCO-UniHuman](https://github.com/lishuhuai527/COCO-UniHuman) | No |
| MediaPipe Pose Heavy, MoveNet Thunder, RTMPose-M, YOLO11x-Pose, Sapiens 1B COCO, OpenPose COCO18 checkpoints and upstream runtimes | Their respective model/framework projects | No |

Review the exact license attached to each code dependency and checkpoint. Dataset terms may differ between annotation and image layers. This project's eventual code license will cover only original files for which the rights holders have authority to license them. It grants no rights to images, annotations, weights, third-party software, names, or institutional marks.
